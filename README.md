# Weeknight Ceramics

A simple portfolio website for Weeknight Ceramics, showcasing functional pottery by Seth Gorelik.

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Tech Stack

- React
- Vite
- CSS
- Vercel
